# LoreBuilder

## Overview
This application is a full-stack web-based application which was originally intended to be a desktop application. However, my current hardware can't use the latest 
frameworks for developing a web-based desktop application. 

This application is intended for game developers, game enthusiasts, Table top players, game designers, or even gamers in general to develop the lore and background of
their characters as much as they want to. The frontend has been emphasized in order to make the application livelier and more engaging wih the user.
